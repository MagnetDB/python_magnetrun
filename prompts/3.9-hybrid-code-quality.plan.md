## L1 — Extract `_plot_variable_impl` / `_plot_variables_impl` ✅

**Completed: 2026-06-10 · branch `rework_analysis`**

### What was done

**File:** `python_magnetrun/hybrid/plotting.py`

- Added `_plot_variable_impl(data, time, system, variable, ylabel, title, ax_series_label, ax, show, save, outlier_result, outlier_strategy, downsample, downsample_method, backend) -> tuple`
  — shared pipeline: stash originals → apply outlier strategy → downsample →
  ax-injection path | resolve backend + plot_overlay + ylabel + scatter + handle_output.

- Added `_plot_variables_impl(hybrid_data, system, variables, read_fn, get_unit_fn, title, layout, show, save, outlier_results, outlier_strategy, downsample, downsample_method, backend) -> tuple`
  — shared multi-variable pipeline: per-variable read/outlier/downsample → DataFrame merge →
  subplots/overlay → **y-axis labels** → **highlight scatter via stash** → output.

- `plot_khz_variable` and `plot_rms_variable` rewritten as thin wrappers:
  read data → compute `unit`/`ylabel`/`title` → call `_plot_variable_impl`.

- `plot_khz_variables` rewritten to close over `read_khz_variable` and `_get_khz_unit`,
  then delegate to `_plot_variables_impl`.

- `plot_rms_variables` rewritten similarly, with **two bug fixes**:
  1. Added missing `downsample` and `downsample_method` parameters.
  2. Added missing y-axis unit labels for subplot axes.
  3. `_scatter_outliers` now receives `downsample`/`downsample_method` (was hardcoded `None, "auto"`).

- Standardised outlier label format: `f"Outliers ({n:,})"` (RMS was missing the `,` formatter).

- kHz highlight mode now uses the stash instead of re-reading data (was already correct; confirmed).

**Tests:** 7 new tests added to `tests/test_hybrid_api.py`:
- `TestPlotVariableImpl`: highlight uses stash, no scatter on non-highlight, ylabel set/not set.
- `TestPlotRmsVariablesBugFixes`: downsample param present, ylabel per variable, downsample forwarded.

## M1 — Unify `log_exception` + `format_exception_location`

3. Delete `log_exception` and `format_exception_location` from `hybrid/utils.py`.

## L2 — Extract `_BinaryFileReaderBase`

**Notes item 1 · Effort L (~1–2 days) · Risk Medium**

`RMSFileReader` (`hybrid/rms/rms_reader.py`) and `VProcessFileReader`
(`hybrid/vprocess/vprocess_reader.py`) are near-identical classes (~95% shared code).

**Minor differences to preserve:**
- Encoding: RMS uses `US-ASCII`; VProcess uses `utf-8`.
- Timestamp conversion: RMS uses `pd.to_datetime(..., utc=True)`; VProcess uses `datetime.fromtimestamp`.
- RMS has `_parse_processed_info()`; VProcess has `_parse_format()` dispatching on format tag.
- VProcess `parse_header()` resets `self.variables = []` / `self.metadata = {}` at the top.

**Plan:**
1. Create `hybrid/_binary_reader_base.py` with abstract `_BinaryFileReaderBase`.
2. Move shared methods: `parse_header`, `_parse_variables`, `_parse_windows`,
   `_parse_frequency`, `_parse_data_helper`, `read_binary_data`, `read`,
   `get_variable_info`, `get_metadata`, `print_summary`.
3. Keep `RMSFileReader` and `VProcessFileReader` as subclasses, overriding only
   encoding, timestamp conversion, and format tag.
4. Merge `RMSVariable` / `VProcessVariable` into a single `ChannelVariable` dataclass
   in the base module.

**Prerequisite for:** Stream 4.6 (Trigger & VProcess integration into `HybridData`).
**Plan separately before starting** — medium risk.
