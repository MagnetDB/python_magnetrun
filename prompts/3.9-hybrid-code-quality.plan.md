## L1 — Extract `_plot_variable_impl` / `_plot_variables_impl` ✅

**Completed: 2026-06-10 · branch `rework_analysis`**

### What was done

**File:** `python_magnetrun/hybrid/plotting.py`

- Added `_plot_variable_impl(data, time, system, variable, ylabel, title, ax_series_label, ax, show, save, outlier_result, outlier_strategy, downsample, downsample_method, backend) -> tuple`
  — shared pipeline: stash originals → apply outlier strategy → downsample →
  ax-injection path | resolve backend + plot_overlay + ylabel + scatter + handle_output.

- Added `_plot_variables_impl(hybrid_data, system, variables, read_fn, get_unit_fn, title, layout, show, save, outlier_results, outlier_strategy, downsample, downsample_method, backend) -> tuple`
  — shared multi-variable pipeline: per-variable read/outlier/downsample → DataFrame merge →
  subplots/overlay → **y-axis labels** → **highlight scatter via stash** → output.

- `plot_khz_variable` and `plot_rms_variable` rewritten as thin wrappers:
  read data → compute `unit`/`ylabel`/`title` → call `_plot_variable_impl`.

- `plot_khz_variables` rewritten to close over `read_khz_variable` and `_get_khz_unit`,
  then delegate to `_plot_variables_impl`.

- `plot_rms_variables` rewritten similarly, with **two bug fixes**:
  1. Added missing `downsample` and `downsample_method` parameters.
  2. Added missing y-axis unit labels for subplot axes.
  3. `_scatter_outliers` now receives `downsample`/`downsample_method` (was hardcoded `None, "auto"`).

- Standardised outlier label format: `f"Outliers ({n:,})"` (RMS was missing the `,` formatter).

- kHz highlight mode now uses the stash instead of re-reading data (was already correct; confirmed).

**Tests:** 7 new tests added to `tests/test_hybrid_api.py`:
- `TestPlotVariableImpl`: highlight uses stash, no scatter on non-highlight, ylabel set/not set.
- `TestPlotRmsVariablesBugFixes`: downsample param present, ylabel per variable, downsample forwarded.

**Test run:** 1071 passed, 7 skipped.

## M3 — Deprecate `processing.correlations` lag functions ✅

**Completed: 2026-06-11 · branch `rework_analysis`**

### What was done

**File:** `python_magnetrun/processing/correlations.py`

- Added `import warnings` and `_normalise_range(r)` helper (converts legacy tuple
  `(start, end)` to dict `{"start": …, "end": …}` for backward compatibility).
- `lag_correlation` replaced with a deprecation shim: emits `DeprecationWarning`,
  normalises `range` in both input dicts, forwards to
  `analysis.synchronization.lag_correlation`.
- `compute_lag` replaced with a deprecation shim: emits `DeprecationWarning`,
  normalises `range` (tuple → dict) in both input dicts, forwards to
  `analysis.synchronization.compute_lag`.
- `crosscorr`, `pearson`, `tlcc`, `wtlcc`, `rwtlcc` unchanged.

No internal callers of the deprecated functions were found (confirmed by grep);
`analysis/processing.py` already imports `compute_lag` from `.synchronization`.

## L2 — Extract `_BinaryFileReaderBase` ✅

**Completed: 2026-06-11 · branch `rework_analysis` · See: [l2-binary-reader-base.plan.md](l2-binary-reader-base.plan.md)**

### What was done

**New file: `python_magnetrun/hybrid/_binary_reader_base.py`**

- `ChannelVariable` dataclass: merges `RMSVariable` and `VProcessVariable`.
  `is_analog = "float" in var_type.lower()` covers both RMS (`"float32"`, `"bit"`)
  and VProcess (`"float32"`, `"dig"`) type strings.
- `_BinaryFileReaderBase`: abstract base with all shared logic.
  - Shared: `parse_header`, `_parse_windows`, `_parse_frequency`,
    `_parse_data_helper`, `read_binary_data`, `read`, `get_variable_info`,
    `get_metadata`, `print_summary`.
  - Abstract: `_validate_format`, `_parse_variables`, `_make_timestamps`.
  - Hook (no-op default): `_parse_extra_header` for format-specific lines.
  - Class attributes: `_encoding = "US-ASCII"`, `_default_sample_width = 0`.

**Updated: `hybrid/rms/rms_reader.py`**

- `RMSFileReader` inherits `_BinaryFileReaderBase`.
- `_encoding = "US-ASCII"`, `_default_sample_width = 257`.
- `_parse_extra_header` handles `"# format"` and `"# processed on"` lines.
- `_make_timestamps` → `pd.to_datetime(raw, unit="s", utc=True)`.
- `get_variable_info()` overrides base to add `byte_size` column.
- `RMSVariable = ChannelVariable` re-export alias for backward compat.

**Updated: `hybrid/vprocess/vprocess_reader.py`**

- `VProcessFileReader` inherits `_BinaryFileReaderBase`.
- `_encoding = "utf-8"`.
- `_parse_variables` handles `"_"` sentinel for missing min/max.
- `_parse_extra_header` handles `"# vprocess data file"` line.
- `_make_timestamps` → `pd.DatetimeIndex([datetime.fromtimestamp(t, tz=UTC) for t in raw])`.
- `VProcessVariable = ChannelVariable` re-export alias for backward compat.

**New tests: `tests/readers/test_binary_reader_base.py`** — 21 tests:
- `TestChannelVariable`: `is_analog`/`byte_size` for all type strings, aliases.
- `TestMakeTimestamps`: round-trip for both subclasses; both produce same UTC datetimes.
- `TestRMSFileReaderHeader` / `TestVProcessFileReaderHeader`: parse_header, metadata,
  variable_info, read_binary_data (synthetic file with self-consistent offset).
- `TestGetMetadataCopy`: `get_metadata()` returns a copy for both subclasses.

**Test run:** 1114 passed, 7 skipped.
