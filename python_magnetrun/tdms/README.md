# Log Parser for LabVIEW/DAQmx Acquisition System

A Python parser for analyzing LabVIEW/DAQmx acquisition system log files from the LNCMI magnet facilities.

## Overview

This parser processes log files generated by the LabVIEW/DAQmx acquisition system and extracts structured information about:

- **ENET box presence tests** - Hardware connectivity checks with OK/KO results
- **Acquisition events** - Start/stop of data acquisition on magnets (M9, M10, etc.)
- **File creation events** - Archive, Overview, Stats, Spike, Default, and ManualTrig files
- **DAQmx/TDMS errors** - Error codes and descriptions from the acquisition system
- **Fault detection events** - SpikeAimant, DefautNums, Courants50Hz
- **File-error associations** - Links errors to the files being created when they occurred

## Log File Format

The parser expects log files with:

- **Timestamp format**: `<day_fr> <date> <time>: <message>`
  - Example: `jeu. 19-09-2019 16:14:33: Test de présence des boitiers ENET`
- **French day abbreviations**: lun., mar., mer., jeu., ven., sam., dim.
- **Mixed French/English messages**
- **Multi-line records**: Some messages (errors, ENET tests) span multiple lines

## Usage

### Command Line

Run the parser on a log file:

```bash
python log_parser.py /path/to/logfile.log
```

Run without arguments to see demo output with sample data:

```bash
python log_parser.py
```

### Output Files

The parser generates two JSON output files in the current directory:

- **`files_with_errors.json`** - Files (Archive/Overview) that encountered DAQ errors
- **`defaut_files.json`** - Fault TDMS files with detection details

### Programmatic Usage

```python
from log_parser import LogParser

# Parse a log file
parser = LogParser("/path/to/logfile.log").parse()

# Get summary statistics
summary = parser.summary()
print(f"Total entries: {summary['total_entries']}")
print(f"Files with errors: {summary['files_with_errors']}")
print(f"Defaut files: {summary['defauts']['files']}")

# Access structured data
for enet_test in parser.enet_tests:
    print(f"ENET test at {enet_test.timestamp}")
    print(f"  OK: {enet_test.ok_count}, KO: {enet_test.ko_count}")
    
for acquisition in parser.acquisitions:
    print(f"{acquisition.action} acquisition on {acquisition.magnet}")

for error in parser.errors:
    print(f"Error {error.error_code}: {error.error_message}")

# Get dictionaries for export
files_with_errors = parser.get_files_with_errors_dict()
defaut_files = parser.get_defaut_files_dict()
```

### Parse from String

```python
log_content = """jeu. 19-09-2019 16:14:33: Test de présence des boitiers ENET
Test A1 : OK
Test A2 : KO
"""

parser = LogParser("/dev/null")
parser.parse_string(log_content)
```

## Data Structures

### Files with Errors Dictionary

Maps filenames to their associated DAQ errors:

```json
{
  "M9_Archive_191002-1445.tdms": {
    "filepath": "F:\\Fichiers_Data\\M9\\Fichiers_Archive\\M9_Archive_191002-1445.tdms",
    "file_type": "Archive",
    "magnet": "M9",
    "file_timestamp": "2019-10-02T14:46:22",
    "errors": [
      {
        "error_code": "-200279",
        "error_message": "GR1&2.lvlib:Acquisition.lvlib:Acquire DAQ NUM.vi",
        "error_description": "Multiple lines of error details...",
        "error_timestamp": "2019-10-03T09:02:49"
      }
    ]
  }
}
```

```json

      "axis": "I_MAX"

  }

```

## Fault Types Detected

- **SpikeAimant** - Voltage spike detected on magnet channel
- **DefautNums** - Numerical fault (e.g., current/voltage limits)
- **Courants50Hz** - 50Hz current ripple detected

## Key Features

- **Automatic encoding detection** - Handles UTF-8, Latin-1, CP1252, ISO-8859-1
- **Natural sorting** - Output files use natsort for proper numerical ordering
- **Error association** - Links DAQ errors to the files being created at the time
- **Fault tracking** - Associates fault events with their corresponding TDMS files
- **Comprehensive summary** - Statistical overview of log contents

## API Reference

### LogParser Class

#### Methods

- **`parse()`** - Parse the log file and return self for chaining
- **`parse_string(content)`** - Parse log content from a string
- **`summary()`** - Get statistical summary of parsed data
- **`get_defaut_files_dict()`** - Get dictionary of fault files
- **`get_files_with_errors_dict()`** - Get dictionary of files with errors

#### Attributes

- **`entries`** - List of all parsed log entries
- **`enet_tests`** - List of ENET test results
- **`acquisitions`** - List of acquisition start/stop events
- **`files_created`** - List of file creation events
- **`errors`** - List of DAQmx errors
- **`defauts`** - List of fault detection events
- **`defaut_files`** - Dictionary of fault TDMS files
- **`files_with_errors`** - Dictionary of files with associated errors

## Example Output

When run, the parser produces:

1. **Console output** with summary statistics and details
2. **JSON files** for programmatic access:
   - `files_with_errors.json` (naturally sorted by filename)
   - `defaut_files.json` (naturally sorted by filename)

## Encoding Notes

The parser automatically tries multiple encodings to handle various log file formats. If all fail, it falls back to UTF-8 with error replacement to ensure parsing continues.
