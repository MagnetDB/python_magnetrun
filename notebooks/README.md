# JupyterLab Notebooks for python_magnetrun

This directory contains Jupyter notebooks for experimenting with python_magnetrun.

## Available Data

- `/workspace/data/` - Sample data files
- `/workspace/srvdata/` - Server data (JSON files)
- `/workspace/examples/` - Example scripts that can be converted to notebooks

## Getting Started

Create a new notebook and try:

```python
import python_magnetrun
from python_magnetrun import MagnetRun
import pandas as pd
import matplotlib.pyplot as plt

# Your experiments here
```
